
PERSONAL MINI-TOOLKIT
Week 8 Final Project - PLP Python Programming

PART 1: TOOLS

Tool 1: Simple Calculator
Description:
The calculator allows users to add, subtract, multiply, and divide two numbers.

Concepts used:
- Variables
- User input and output
- Float numbers
- If, elif, and else statements
- Functions
- Try and except
- F-strings


Tool 2: To-Do List
Description:
The to-do list allows users to add new tasks, view saved tasks, and remove tasks while the program is running.

Concepts used:
- Lists
- Variables
- While loops
- For loops
- If, elif, and else statements
- List methods such as append() and pop()
- User input and output
- F-strings


Tool 3: Number Guessing Game
Description:
The game chooses a random number between 1 and 10 and asks the user to guess it until they find the correct number.

Concepts used:
- Variables
- Random module
- While loops
- If, elif, and else statements
- User input and output
- Try and except
- F-strings

PART 3: MENU BEHAVIOUR

The program displays a welcome message when it starts.
The menu displays four options.
The user chooses a tool by entering a number.
The selected tool runs when the user enters a valid choice.
The menu returns after the selected tool finishes.
If the user enters an invalid choice, the program displays a polite error message.
The program ends when the user chooses option 4.
A friendly goodbye message appears before the program closes.
